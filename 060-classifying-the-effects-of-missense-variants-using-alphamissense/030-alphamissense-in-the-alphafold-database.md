# AlphaMissense en la Base de Datos AlphaFold

En la Base de Datos AlphaFold, ahora puedes explorar las estructuras predichas para las proteínas humanas canónicas e intercambiar sin problemas entre dos representaciones visuales clave: la calidad del modelo de estructura (pLDDT) y las puntuaciones promedio de patogenicidad de AlphaMissense.

Los datos de variantes se muestran utilizando un mapa de calor innovador e interactivo y una visualización 3D, que ofrecen información sobre las implicaciones más amplias de los cambios específicos en los residuos. El mapa de calor puede ayudar a interpretar áreas funcionales importantes con una patogenicidad predicha más alta.

Tú puedes filtrar el mapa de calor por categoría y modificar el rango para las categorías según tu enfoque.

La actualización de la AFDB ayuda significativamente a los investigadores a identificar áreas estructurales para guiar sus investigaciones sobre la función de las proteínas y proporciona un fácil acceso para descargar los datos.
