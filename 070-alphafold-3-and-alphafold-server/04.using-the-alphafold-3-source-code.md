# Usando el código fuente de AlphaFold 3

Instalar AlphaFold 3 localmente te da el control total sobre la predicción de estructuras. Esta es la forma más potente y adaptable de usar AlphaFold 3. Sin embargo, el software requiere acceso a hardware de última generación (es decir, GPUs con el tamaño máximo de RAM) o una máquina virtual y requiere un alto grado de habilidad informática para instalar y ejecutar.

## **Instalando el código fuente de AlphaFold 3**

El código fuente de AlphaFold 3 está disponible en el [repositorio oficial de GitHub](https://github.com/google-deepmind/alphafold3). Este repositorio proporciona una implementación de la pipeline de inferencia de AlphaFold 3.

Los parámetros del modelo deben obtenerse directamente de Google, como se detalla en la sección “[Obtaining model parameters](https://github.com/google-deepmind/alphafold3?tab=readme-ov-file#obtaining-model-parameters)” en GitHub.

AlphaFold 3 requiere un entorno Linux; otros sistemas operativos no son compatibles. La instalación completa requiere hasta 1 TB de espacio en disco, para bases de datos genéticas (se recomienda fuertemente el almacenamiento SSD). Se requiere una GPU NVIDIA con capacidad de cómputo 7.0 o superior. Para estructuras de proteínas más grandes, se recomiendan GPUs con mayor capacidad de memoria.

Para referencia, las entradas con hasta 5,120 tokens pueden caber en una sola NVIDIA A100 80 GB o NVIDIA H100 80 GB. La precisión numérica ha sido verificada en ambos tipos de hardware.

Alphafold 3, al igual que AlphaFold 2, requiere acceso local a grandes bases de datos, incluyendo PDB, MGnify, UniProt, UniRef90, NT, RFam, RNACentral, y una versión modificada de BFD.

Si no tienes acceso a dicho hardware, una de las posibilidades es usar una máquina virtual (equipada según estas especificaciones) de cualquier proveedor de Cloud.

## **Consideraciones para las primeras predicciones de estructuras**

El tiempo de ejecución de la pipeline de datos (es decir, la búsqueda de secuencias genéticas y la búsqueda de plantillas) puede variar significativamente dependiendo del tamaño de la entrada y el número de secuencias homólogas encontradas, así como del hardware disponible (la velocidad del disco puede influir en particular en la velocidad de la búsqueda genética).

AlphaFold 3 se puede ejecutar de manera eficiente en una sola GPU NVIDIA A100 80 GB. Esta configuración es adecuada para predicciones de alto rendimiento.

Para una mejor gestión de recursos, la pipeline se puede dividir en:

* Etapa de la pipeline de datos (intensiva en CPU): Esta parte realiza la búsqueda de secuencias genéticas y la identificación de plantillas. La velocidad del disco afecta significativamente el rendimiento de la búsqueda genética, por lo que recomendamos usar un disco SSD.
* Etapa de inferencia del modelo (intensiva en GPU): Esta etapa predice la estructura utilizando el modelo entrenado.

Si deseas mejorar el rendimiento, se recomienda aumentar la velocidad del disco (por ejemplo, aprovechando un sistema de archivos respaldado por RAM) o aumentar los núcleos de CPU disponibles y agregar más paralelización.

Para secuencias con MSAs profundas, el uso de RAM puede exceder los 64 GB recomendados.

Por favor, revisa cuidadosamente la “[Installation and Running Your First Prediction](https://github.com/google-deepmind/alphafold3/blob/main/docs/installation.md)” para obtener orientación sobre la instalación y la ejecución de predicciones. También puedes ejecutar la pipeline en etapas para optimizar la utilización de recursos. Consulta la nota sobre [Performance](https://github.com/google-deepmind/alphafold3/blob/main/docs/performance.md).

## Formato de entrada de AlphaFold 3

AlphaFold 3 introduce un formato de entrada basado en JSON flexible que ofrece una personalización expandida. Esto difiere del formato de AlphaFold Server y permite a los usuarios definir ensamblajes biomoleculares complejos. Las características clave incluyen:

* Cadenas de proteínas, ARN y ADN, con opciones para residuos modificados.
* Alineaciones múltiples de secuencias personalizadas (MSAs) para proteínas y ARN.
* Plantillas estructurales para cadenas de proteínas.
* Especificación de ligandos utilizando códigos del [Diccionario de Componentes Químicos (CCD)](https://www.wwpdb.org/data/ccd), cadenas SMILES o entradas definidas por el usuario en formato mmCIF. GitHub AlphaFold 3 soporta cualquier ligando personalizado sin restricciones.
* Definiciones de enlaces covalentes entre entidades.
* Soporte para múltiples semillas aleatorias para generar predicciones estructurales alternativas.

## Compatibilidad con AlphaFold Server JSON

AlphaFold 3 proporciona un conversor en *run\_alphafold.py* que traduce los archivos JSON de AlphaFold Server al formato AlphaFold 3. Para más información, consulta “[AlphaFold 3 Input](https://github.com/google-deepmind/alphafold3/blob/main/docs/input.md#alphafold-3-input)”. Puntos clave:

* El conversor asigna identificadores de secuencia únicos donde sea necesario.
* Al menos una semilla aleatoria es requerida para AlphaFold 3. Si un JSON convertido carece de esto, el conversor asignará una automáticamente.
* AlphaFold Server trata a los iones y ligandos por separado, AlphaFold 3 trata a los iones como ligandos.
* Ten en cuenta que los glicanos especificados en los JSON de AlphaFold Server no son soportados en la conversión.

## Consideraciones especiales

Empieza con proteínas más pequeñas o con objetivos bien caracterizados para familiarizarte con el flujo de trabajo y los parámetros.

Realiza predicciones individuales proporcionando una ruta de archivo JSON o múltiples predicciones proporcionando una ruta de directorio.

Tu institución puede tener una instalación central de AF3, así que deberías referirte a las guías locales sobre cómo ejecutarla. De lo contrario, podrías querer contactar a tus administradores de sistema para asistencia con la instalación de AF3 y considerar hacer una instalación central para los usuarios locales.

Para una guía más detallada, por favor consulta el [README](https://github.com/google-deepmind/alphafold3/blob/main/docs/input.md) de AlphaFold 3 Input.
