# AlphaFold 3 y AlphaFold Server

AlphaFold 3 es una nueva versión de AlphaFold. Tiene capacidades adicionales, especialmente la habilidad de predecir las estructuras de complejos que contienen múltiples moléculas no proteicas (por ejemplo, ADN, ARN, ligandos). Para proyectos no comerciales, AlphaFold 3 está disponible como un servicio a través de [AlphaFold Server](https://alphafoldserver.com/) y como código fuente a través del [AlphaFold 3 GitHub repository](https://github.com/google-deepmind/alphafold3).

Esta sección asume familiaridad con AlphaFold 2. Esto incluye una comprensión de las puntuaciones de confianza, fortalezas y limitaciones, así como un conocimiento de la tecnología subyacente. Para aquellos nuevos en AlphaFold, se recomienda encarecidamente leer la primera sección, “[What is AlphaFold?](https://www.ebi.ac.uk/training/online/courses/alphafold/an-introductory-guide-to-its-strengths-and-limitations/what-is-alphafold/)” ya que cubre principios esenciales que son fundamentales para comprender tanto AlphaFold 2 como AlphaFold 3.

### Al final de esta sección, tú podrás:

* Entender lo que AlphaFold 3 puede y no puede hacer.
* Determinar si debes usar AlphaFold 2 o AlphaFold 3 para ayudar con tus preguntas de investigación.
* Generar predicciones de estructura de AlphaFold 3 usando AlphaFold Server para proyectos no comerciales.
* Interpretar las predicciones de estructura proporcionadas por AlphaFold 3.
