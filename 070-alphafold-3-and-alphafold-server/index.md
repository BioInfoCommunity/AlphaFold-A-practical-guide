# AlphaFold 3 y AlphaFold Server

AlphaFold 3 es una nueva versión de AlphaFold. Tiene capacidades adicionales, especialmente la capacidad de predecir las estructuras de complejos que contienen múltiples moléculas no proteicas (por ejemplo, ADN, ARN, ligandos). Para proyectos no comerciales, AlphaFold 3 está disponible como un servicio a través de [AlphaFold Server](https://alphafoldserver.com/) y como código fuente a través del [repositorio de GitHub de AlphaFold 3](https://github.com/google-deepmind/alphafold3).

Esta sección asume familiaridad con AlphaFold 2. Esto incluye una comprensión de las puntuaciones de confianza, fortalezas y limitaciones, así como una comprensión de la tecnología subyacente. Para aquellos nuevos en AlphaFold, se recomienda encarecidamente leer la primera sección, “[¿Qué es AlphaFold?](https://www.ebi.ac.uk/training/online/courses/alphafold/an-introductory-guide-to-its-strengths-and-limitations/what-is-alphafold/)” ya que cubre principios esenciales que son fundamentales para entender tanto AlphaFold 2 como AlphaFold 3.

### Al final de esta sección podrás:

* Entender qué puede y qué no puede hacer AlphaFold 3.
* Determinar si usar AlphaFold 2 o AlphaFold 3 para ayudar con tus preguntas de investigación.
* Generar predicciones estructurales de AlphaFold 3 usando AlphaFold Server para proyectos no comerciales.
* Interpretar las predicciones estructurales proporcionadas por AlphaFold 3.
