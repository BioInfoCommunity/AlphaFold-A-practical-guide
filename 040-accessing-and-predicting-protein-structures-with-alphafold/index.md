# Accediendo y prediciendo estructuras de proteínas con AlphaFold 2

AlphaFold2 es una herramienta potente para la predicción de estructuras de proteínas. Sin embargo, la mejor manera de acceder a ella depende de tus necesidades y recursos específicos. Las opciones principales son:

* Usar el [código fuente](https://github.com/google-deepmind/alphafold) de AlphaFold2 para la predicción de estructuras de proteínas.
* Un enfoque basado en la nube a través de [ColabFold](https://colab.research.google.com/github/sokrypton/ColabFold/blob/main/AlphaFold2.ipynb).
* Acceder a la [Base de datos de estructuras de proteínas de AlphaFold](https://alphafold.ebi.ac.uk/) gratuita. Desarrollada por Google DeepMind en colaboración con EMBL-EBI, ofrece una interfaz fácil de usar y más de 200 millones de estructuras de proteínas predichas.
* Usar software especializado que incorpore el algoritmo y/o los datos de AlphaFold.

### Al final de esta sección, tú podrás:

* Describir las diferencias clave entre usar el código fuente de AlphaFold, los cuadernos de Google Colab o la Base de datos de estructuras de proteínas de AlphaFold para predecir estructuras de proteínas.
* Determinar el mejor enfoque para usar AlphaFold, basándote en tus recursos computacionales, experiencia en programación y necesidad de personalización.
* Recordar las formas de acceder a las predicciones precalculadas de la Base de datos de estructuras de proteínas de AlphaFold.
* Identificar otros recursos para acceder y predecir estructuras de proteínas y macromoléculas.
