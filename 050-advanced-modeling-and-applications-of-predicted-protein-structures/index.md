# Modelado avanzado y aplicaciones de estructuras proteicas predichas

En las secciones anteriores, cubrimos los conceptos básicos de AlphaFold2, incluyendo cómo funciona, las diferentes métricas utilizadas para evaluar las estructuras predichas y las diferentes formas de acceder y predecir estructuras utilizando el algoritmo.

Esta sección cubrirá cómo usar AlphaFold para modelado avanzado, como predecir interacciones proteína-proteína, modelar complejos proteicos grandes y estados estructurales alternativos. Aprenderás cómo usar AlphaFold para obtener nuevas perspectivas sobre la estructura y función de las proteínas.

### Al final de esta sección, tú podrás:

* Recordar las diferentes formas de usar AlphaFold para modelado avanzado utilizando el código fuente, los cuadernos de Colab y la base de datos.
* Usar AlphaFold para predecir estructuras proteicas.
* Recordar las diferentes formas de personalizar el proceso de predicción de estructuras de AlphaFold para satisfacer necesidades específicas.
* Interpretar y analizar las predicciones de estructura de AlphaFold.
